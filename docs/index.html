扫码登录

B 站官方二维码接口。Cookie 写入本地文件，只发送给 api.bilibili.com，永不出你的电脑。

时间段筛选

日期范围、类型、关键词、状态四维筛选。每条评论可一键跳回原视频核对。

低频删除

每条随机 5-12 秒、每 20 条休息 30-60 秒，风控信号自动中止。可随时停止、重开续跑。

实时进度

每删一条即回写本地数据文件，进度条反映真实状态。关闭窗口，后台任务照常运行。

保留名单

批量删除前，把想留的评论标记为保留——比如某条有纪念意义的评论。

全量快照

只读快照视图，不随删除变化。删完之后，仍可回看完整的历史清单。

慢，是刻意的。

git clone https://github.com/Mal-Suen/BiliCommentManager.git
pip install -r requirements.txt
python bili_comment_gui.py

诚实声明。

  • 删除不可恢复。删除前，全部评论内容已留档在本地 my_comments.json。
  • 评论列表来自第三方索引 AICU，只暴露公开 uid、不带 Cookie；索引有滞后，部分网络环境可能不可达。
  • 删除调用 B 站网页端同款接口，属非官方 API 用法；请保持默认低频节奏。
  • 未签名 exe 首次运行会有 SmartScreen 蓝色警告，属正常现象（「更多信息 → 仍要运行」）。
  • 本工具与哔哩哔哩公司无关，仅供个人管理自己的评论使用。
